## 学习目标

- 说清一个工具由哪些部分组成
- 会写工具描述与参数 schema
- 知道模型只输出调用意图，运行时才真正执行

## 2.1 一个工具由四部分组成

| 部分 | 作用 | 谁使用 |
|-|-|-|
| 名称 | 唯一标识，模型按名称选择 | 模型 + 运行时 |
| 描述 | 说明什么时候该用、什么时候不该用 | 模型 |
| 参数 schema | 规定参数名、类型与是否必填 | 模型 + 运行时 |
| 执行函数 | 真正访问网络、数据库或文件 | 运行时 |

前三个部分决定模型“会不会用、怎么传参”；第四个部分决定调用时“实际发生什么”。模型不会自己执行 Python 函数。

## 2.2 工具描述与参数 schema

以天气工具为例：

```python
WEATHER_TOOL = {
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询指定城市未来几天的天气。用户问天气、温度、是否下雨时使用。",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {
                    "type": "string",
                    "description": "城市名，例如 beijing 或 shanghai",
                },
                "days": {
                    "type": "integer",
                    "description": "查询天数，1 到 7，默认 1",
                },
            },
            "required": ["city"],
        },
    },
}
```

描述要写清两件事：

1. **什么时候用**：用户问天气、温度、降雨时；
2. **什么时候不用**：不要用于历史气候研究、新闻检索。

参数描述要给出格式与示例。模型只能看到这些文字，看不到你的实现代码。

## 2.3 模型返回的是调用意图

开启工具后，模型可能返回：

```json
{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_001",
            "type": "function",
            "function": {
              "name": "get_weather",
              "arguments": "{\"city\": \"beijing\"}"
            }
          }
        ]
      }
    }
  ]
}
```

注意 `arguments` 是一个 JSON 字符串，需要先 `json.loads`。运行时要做三件事：

1. 按 `name` 找到函数；
2. 校验参数；
3. 执行函数，把结果作为新的 `tool` 消息放回上下文。

<div class="v-callout is-warn">
  <strong>不要相信模型传来的参数</strong>
  <p>模型可能给不存在的城市、超范围的天数，甚至拼接恶意字符串。执行函数前必须在代码里校验类型、范围与格式。</p>
</div>

## 2.4 工具描述写不好的后果

- 描述太短：模型不知道何时调用，永远只用聊天回答；
- 描述太宽：模型把无关任务也交给它，浪费调用；
- 参数没有约束：模型传入 `days=100`，工具直接失败；
- 名称含糊：多个工具名字相似，模型频繁选错。

<div class="v-callout is-tip">
  <strong>先写描述，再写实现</strong>
  <p>把工具当成给别人用的接口：先想清楚它在什么场景被调用、需要哪些参数，再写执行函数。</p>
</div>

## 小结

- 工具由名称、描述、参数 schema 与执行函数组成；
- 模型只输出调用意图，运行时才真正执行；
- `arguments` 是 JSON 字符串，必须先解析再校验；
- 描述决定模型何时用，参数约束决定调用是否安全。
