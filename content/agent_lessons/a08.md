## 学习目标

- 解析模型输出中的 Action 与 Finish
- 写出有最大步数的 ReAct 循环
- 把 observation 放回消息并处理解析失败

## 3.5 先约定输出格式

手写循环时，先固定模型输出格式，再写解析器：

```text
Thought: 需要查询北京天气
Action: get_weather {"city": "beijing"}
```

或者结束：

```text
Thought: 信息足够
Finish: 北京今天 26℃
```

格式越简单，解析越稳定。也可以要求模型直接输出 JSON，但需要处理 JSON 解析失败与字段缺失。

## 3.6 解析 Action 与 Finish

```python
import json

def parse_model_output(text: str) -> dict:
    line = text.strip().splitlines()[-1].strip()

    if line.startswith("Action:"):
        body = line[len("Action:"):].strip()
        name, _, raw_args = body.partition(" ")
        if not name or not raw_args:
            return {"type": "invalid", "error": "Action 缺少参数"}
        try:
            arguments = json.loads(raw_args)
        except json.JSONDecodeError:
            return {"type": "invalid", "error": "参数不是合法 JSON"}
        if not isinstance(arguments, dict):
            return {"type": "invalid", "error": "参数必须是对象"}
        return {"type": "action", "tool": name, "arguments": arguments}

    if line.startswith("Finish:"):
        answer = line[len("Finish:"):].strip()
        if not answer:
            return {"type": "invalid", "error": "Finish 为空"}
        return {"type": "finish", "answer": answer}

    return {"type": "invalid", "error": "无法解析模型输出"}
```

解析器只做一件事：把文本变成结构化动作。它不执行工具，也不调用模型。

## 3.7 循环骨架

```python
messages = [
    {"role": "system", "content": SYSTEM_PROMPT},
    {"role": "user", "content": question},
]

for step in range(MAX_STEPS):
    text = call_llm(messages)
    action = parse_model_output(text)

    if action["type"] == "finish":
        return action["answer"]

    if action["type"] == "invalid":
        messages.append({"role": "assistant", "content": text})
        messages.append({"role": "user", "content": "格式错误，请重新输出 Action 或 Finish"})
        continue

    observation = call_tool(action["tool"], action["arguments"])
    messages.append({"role": "assistant", "content": text})
    messages.append({"role": "tool", "content": json.dumps(observation, ensure_ascii=False)})

return "达到最大步数，任务未完成"
```

循环四件事：调用模型、解析输出、执行工具、把结果写回消息。

## 3.8 常见循环故障

| 故障 | 现象 | 处理 |
|-|-|-|
| 无限循环 | 一直调用同一个工具 | 最大步数 + 重复动作检测 |
| 解析失败 | 模型输出自由文本 | 提示重新按格式输出，连续失败则终止 |
| 工具失败 | 参数错误或超时 | 错误作为观察返回，不抛出循环 |
| 提前结束 | 没有工具结果就 Finish | 规则检查或提示要求基于观察回答 |

<div class="v-callout is-warn">
  <strong>循环里不要吞掉错误</strong>
  <p>解析失败与工具失败都要让模型看到。静默重试或直接崩溃，都会让问题难以定位。</p>
</div>

## 小结

- 先约定输出格式，再写解析器；
- 解析器把文本变成 action / finish / invalid；
- 循环依次做调用模型、解析、执行工具、写回观察；
- 最大步数、解析失败与重复动作都要有终止策略。
