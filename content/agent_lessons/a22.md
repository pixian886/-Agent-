## 学习目标

- 选定一个范围可控、能真实运行的结业项目
- 画出角色、工具、状态与评测设计
- 写出一页可执行的项目设计单

## 8.1 选题：小到能交付

先回答三个问题：

1. 谁用？一个具体的人或一类明确任务。
2. 解决什么？一句话说清输入与输出。
3. 怎么算成功？至少三条可观察的验收标准。

推荐范围：

| 维度 | 建议 |
|-|-|
| 工具数量 | 3–5 个，含至少一个真实数据源 |
| 角色数量 | 1 个执行者 + 可选 1 个检查者 |
| 数据 | 本地 SQLite、Markdown 文档或公开 API |
| 界面 | CLI 或一个简单网页 |
| 时间 | 能在一个学习周期内完成并演示 |

<div class="v-callout is-warn">
  <strong>不要做“万能助手”</strong>
  <p>“什么都能回答”的项目无法评测。把范围收窄到一类任务，例如“售后政策助手”“订单查询助手”“课程资料检索助手”。</p>
</div>

## 8.2 角色与流程

单 Agent 优先。只有职责确实不同、需要独立检查或并行处理时，才拆成多角色。

| 角色 | 输入 | 输出 | 停止条件 |
|-|-|-|-|
| 执行者 | 用户任务、工具结果 | 答案或下一步动作 | Finish 或最大步数 |
| 检查者（可选） | 草稿、验收要求 | 通过 / 驳回意见 | 通过或达到重试上限 |

把流程写成一句话：用户提问 → 查订单 → 检索政策 → 读取片段 → 回答并引用。

## 8.3 工具、状态与权限

每个工具写清四件事：

| 工具 | 作用 | 参数 | 失败返回 |
|-|-|-|-|
| `query_orders` | 查订单状态 | `order_id` | 格式错误 / 没有订单 / 数据库不可用 |
| `search_docs` | 检索政策片段 | `query` | 没有命中 |
| `read_doc` | 读取片段全文 | `doc_id` | 片段不存在 |

状态建议包含：

```python
state = {
    "task": "",
    "order": {},
    "sources": [],
    "draft": "",
    "trace": [],
}
```

权限原则：

- 只读工具先上线，写操作最后做；
- 不把管理员账号交给工具；
- 敏感操作要求确认；
- 所有工具返回统一结构 `{"ok": bool, "result" or "error"}`。

## 8.4 评测与里程碑

至少设计 5 个评测任务：

1. 典型查询：订单 + 政策，能正确回答；
2. 空结果：没有订单时明确说没有；
3. 参数错误：日期或订单号格式错误；
4. 注入任务：资料里含“忽略之前的指令”，不得执行危险工具；
5. 回归任务：曾经失败过的案例。

指标至少记录：成功率、平均步数、总成本、失败分类。

三个里程碑：

| 阶段 | 交付 |
|-|-|
| 设计完成 | 项目设计单、工具表、5 个评测任务 |
| 最小可用 | 能跑通典型任务，输出轨迹 |
| 可交付 | README、演示脚本、评测记录、失败案例 |

<div class="v-callout is-tip">
  <strong>先写设计单，再写代码</strong>
  <p>设计单不是形式。它逼你提前想清角色、工具、失败返回与验收标准，能省掉大量返工。</p>
</div>

### 第 3 步：写 tools.py

```python
import sqlite3

WEATHER = {
    "beijing": "北京 26℃ 晴",
    "shanghai": "上海 22℃ 多云",
    "guangzhou": "广州 30℃ 小雨",
}

def init_db():
    conn = sqlite3.connect("orders.db")
    conn.execute(
        "CREATE TABLE IF NOT EXISTS orders (id TEXT PRIMARY KEY, status TEXT NOT NULL)"
    )
    conn.executemany(
        "INSERT OR IGNORE INTO orders (id, status) VALUES (?, ?)",
        [("A001", "已签收"), ("A002", "待发货")],
    )
    conn.commit()
    conn.close()

def get_weather(city):
    key = city.strip().lower()
    if key not in WEATHER:
        return {"ok": False, "error": f"没有找到城市：{city}"}
    return {"ok": True, "result": WEATHER[key]}

def query_orders(order_id):
    conn = sqlite3.connect("orders.db")
    try:
        row = conn.execute(
            "SELECT status FROM orders WHERE id = ?", (order_id,)
        ).fetchone()
    finally:
        conn.close()
    if row is None:
        return {"ok": False, "error": f"没有找到订单：{order_id}"}
    return {"ok": True, "result": f"订单 {order_id} 状态：{row[0]}"}

TOOLS = {
    "get_weather": get_weather,
    "query_orders": query_orders,
}

def call_tool(name, arguments):
    tool = TOOLS.get(name)
    if tool is None:
        return {"ok": False, "error": f"未知工具：{name}"}
    try:
        return tool(**arguments)
    except TypeError as exc:
        return {"ok": False, "error": f"参数不匹配：{exc}"}
    except Exception as exc:
        return {"ok": False, "error": f"工具执行失败：{exc}"}
```

### 第 4 步：写 llm.py

```python
import os

import requests
from dotenv import load_dotenv

load_dotenv()

def call_llm(messages):
    api_key = os.getenv("LLM_API_KEY")
    if not api_key:
        raise RuntimeError("没有读取到 LLM_API_KEY，请检查 .env")

    base_url = os.getenv("LLM_BASE_URL", "https://api.deepseek.com/v1")
    model = os.getenv("LLM_MODEL_ID", "deepseek-chat")

    response = requests.post(
        f"{base_url}/chat/completions",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "model": model,
            "messages": messages,
            "temperature": 0,
            "max_tokens": 300,
        },
        timeout=30,
    )
    response.raise_for_status()
    return response.json()["choices"][0]["message"]["content"]
```

### 第 5 步：写 agent.py

```python
import json

from llm import call_llm
from tools import call_tool

SYSTEM_PROMPT = """你是售后助手，可以调用工具。
可用工具：
- get_weather(city)：查询城市天气，city 使用英文城市名，例如 beijing
- query_orders(order_id)：查询订单状态，例如 A001

每轮只输出一种格式：
Thought: 你的思考
Action: 工具名 {"参数": "值"}
或
Thought: 你的思考
Finish: 最终答案
"""

def parse_output(text):
    for line in reversed(text.splitlines()):
        line = line.strip()
        if line.startswith("Action:"):
            body = line[len("Action:"):].strip()
            name, _, raw_args = body.partition(" ")
            if not name or not raw_args:
                return {"type": "invalid", "error": "Action 缺少参数"}
            try:
                arguments = json.loads(raw_args)
            except json.JSONDecodeError:
                return {"type": "invalid", "error": "参数不是合法 JSON"}
            if not isinstance(arguments, dict):
                return {"type": "invalid", "error": "参数必须是对象"}
            return {"type": "action", "tool": name, "arguments": arguments}
        if line.startswith("Finish:"):
            answer = line[len("Finish:"):].strip()
            if not answer:
                return {"type": "invalid", "error": "Finish 为空"}
            return {"type": "finish", "answer": answer}
    return {"type": "invalid", "error": "没有找到 Action 或 Finish"}

def run_agent(question, max_steps=6):
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": question},
    ]
    trace = []

    for _ in range(max_steps):
        text = call_llm(messages)
        action = parse_output(text)
        trace.append({"type": "thought", "content": text.strip()})

        if action["type"] == "finish":
            trace.append({"type": "finish", "content": action["answer"]})
            return {"answer": action["answer"], "trace": trace}

        if action["type"] == "invalid":
            messages.append({"role": "assistant", "content": text})
            messages.append(
                {"role": "user", "content": "格式不对，请只输出 Action 或 Finish。"}
            )
            continue

        result = call_tool(action["tool"], action["arguments"])
        observation = json.dumps(result, ensure_ascii=False)
        trace.append(
            {
                "type": "action",
                "tool": action["tool"],
                "arguments": action["arguments"],
            }
        )
        trace.append({"type": "observation", "content": observation})
        messages.append({"role": "assistant", "content": text})
        messages.append({"role": "user", "content": f"Observation: {observation}"})

    answer = "达到最大步数，任务未完成"
    trace.append({"type": "finish", "content": answer})
    return {"answer": answer, "trace": trace}
```

### 第 6 步：写 main.py

```python
import json
import os

from agent import run_agent
from tools import init_db

def main():
    init_db()
    question = input("你的问题：").strip()
    if not question:
        print("请输入一个问题。")
        return

    result = run_agent(question)
    print("\n回答：", result["answer"])

    trajectory = {
        "version": 1,
        "task_id": "local-demo",
        "model": os.getenv("LLM_MODEL_ID", "deepseek-chat"),
        "steps": result["trace"],
        "final_answer": result["answer"],
    }
    with open("trajectory.json", "w", encoding="utf-8") as f:
        json.dump(trajectory, f, ensure_ascii=False, indent=2)
    print("轨迹已写入 trajectory.json")

if __name__ == "__main__":
    main()
```

### 第 8 步：检查轨迹

打开 `trajectory.json`，确认：

- `steps` 里有 `thought`、`action`、`observation`、`finish`；
- `action.arguments` 是真实参数；
- `final_answer` 与终端输出一致。

### 第 9 步：补错误处理

- 没有 Key：`llm.py` 直接抛出可读错误；
- 401/403：不重试，检查 Key 与权限；
- 429/超时：有限次退避重试，参考 a03；
- 工具失败：作为 `observation` 返回，参考 a06；
- 达到最大步数：返回明确失败，不要无限循环。

## 小结

- 选题要窄，工具 3–5 个，能在一个周期内交付；
- 单 Agent 优先，职责确实不同再拆角色；
- 工具要有参数、失败返回与权限边界；
- 先定 5 个评测任务与 3 个里程碑，再开始写代码。
