## 学习目标

- 能在自己的电脑上安装 Python 3.10 及以上版本
- 能创建并运行第一个 `.py` 文件
- 会使用命令行、虚拟环境与 `pip` 管理依赖
- 能读懂最常见的 traceback

## 1.1 安装 Python

打开 Python 官网，下载 Python 3.10 或更高版本。Windows 安装时务必勾选 **Add python.exe to PATH**，这样终端才能直接识别 `python` 命令。

安装完成后，打开终端输入：

```bat
python --version
```

如果看到 `Python 3.x.x`，说明安装成功。

## 1.2 安装 VS Code 并运行第一个程序

安装 VS Code 后，再安装 Python 扩展。新建 `hello.py`，写入：

```python
print("Hello, Python!")
```

保存后，可以在 VS Code 右上角点击运行，也可以在终端执行：

```bat
python hello.py
```

终端会输出 `Hello, Python!`。这就是你的第一个 Python 程序。

## 1.3 命令行与虚拟环境

终端（Windows 的 PowerShell 或命令提示符）是你和 Python 交互的地方。常用命令：

```bat
cd 项目目录
python hello.py
python --version
```

虚拟环境把当前项目的依赖和电脑上的其他项目隔离开。进入项目目录后执行：

```bat
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux 使用：

```bash
python -m venv .venv
source .venv/bin/activate
```

激活后，终端提示符前面会出现 `(.venv)`。之后安装的包只属于这个项目。

## 1.4 pip 与依赖清单

```bat
pip install requests
pip list
pip freeze > requirements.txt
```

- `pip install` 安装第三方包；
- `pip list` 查看已安装的包；
- `pip freeze > requirements.txt` 把当前依赖写进文件，换电脑时可以按清单安装：

```bat
pip install -r requirements.txt
```

<div class="v-callout is-tip">
  <strong>每个项目一个虚拟环境</strong>
  <p>不要把包装到系统 Python 里。项目出问题时，删掉 <code>.venv</code> 重新创建即可，不会影响其他项目。</p>
</div>

## 1.5 读 traceback 与常见报错

程序出错时，终端会打印一串 traceback。读法是从下往上：

1. 最后一行是错误类型和原因；
2. 往上一行找到出错的文件和行号；
3. 再到代码里对应位置检查。

```text
Traceback (most recent call last):
  File "hello.py", line 2, in <module>
    print(age)
NameError: name 'age' is not defined
```

意思是 `hello.py` 第 2 行使用了未定义的变量 `age`。

<div class="v-callout is-warn">
  <strong>命令找不到</strong>
  <p>如果终端提示「python 不是内部或外部命令」，通常是安装时没有勾选 Add to PATH。重新安装并勾选即可。</p>
</div>

<div class="v-callout is-warn">
  <strong>中文乱码</strong>
  <p>确保文件保存为 UTF-8。VS Code 右下角可以看到当前编码。</p>
</div>

## 小结

- Python 安装时勾选 Add to PATH；
- 用 `python --version` 验证安装；
- 每个项目使用独立的 `.venv`，用 `pip` 安装依赖；
- 出错时从 traceback 最后一行往上读，先定位文件和行号。
