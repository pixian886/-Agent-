## 学习目标

- 理解变量、赋值和基本数据类型
- 能用 `input()` 读取输入，用 `print()` 输出结果
- 能完成一个「输入姓名和年龄，输出自我介绍」的小程序

## 2.1 变量与赋值

变量可以理解成一个贴了标签的盒子：标签是变量名，盒子里装的是值。

```python
age = 18
name = "小明"
print(age)
print(name)
```

变量名只能包含字母、数字和下划线，不能以数字开头。推荐使用有意义的英文单词，例如 `age`、`name`、`total`。

## 2.2 基本数据类型

| 类型 | 例子 | 说明 |
|-|-|-|
| `int` | `18` | 整数 |
| `float` | `3.14` | 小数 |
| `str` | `"Python"` | 字符串 |
| `bool` | `True` / `False` | 布尔值 |
| `None` | `None` | 空值 |

用 `type()` 可以查看一个值的类型：

```python
print(type(18))
print(type("18"))
```

## 2.3 输入与输出

`input()` 读取的内容永远是字符串。如果要做数学计算，需要先用 `int()` 或 `float()` 转换。

```python
name = input("你的名字：")
age = int(input("你的年龄："))
print(f"你好，{name}，你今年 {age} 岁。")
```

## 2.4 运算符与字符串

常用运算符：

```python
a = 7
b = 2

print(a + b)   # 9
print(a - b)   # 5
print(a * b)   # 14
print(a / b)   # 3.5
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 49
```

字符串可以用 `+` 拼接，也可以用 f-string 插入变量：

```python
first = "Py"
second = "thon"
print(first + second)

name = "小明"
print(f"你好，{name}")
```

## 小结

- 变量是带标签的盒子，赋值用 `=`；
- `input()` 返回字符串，计算前要转换类型；
- f-string 是拼接字符串最方便的方式；
- `type()` 可以查看数据类型。
