## 学习目标

- 能用 `if / elif / else` 做条件判断
- 能用 `for` 和 `while` 重复执行代码
- 知道 `break` 与 `continue` 的作用

## 3.1 布尔值与比较

比较运算会得到 `True` 或 `False`：

```python
score = 75

print(score >= 60)   # True
print(score == 100)  # False
print(score != 0)    # True
```

多个条件可以用 `and`、`or`、`not` 组合：

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)  # True
```

## 3.2 if / elif / else

条件判断根据结果选择执行哪一段代码。Python 用缩进表示代码块。

```python
score = 75

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

这段代码会输出 `及格`。

## 3.3 while 循环

`while` 在条件成立时反复执行。一定要让条件有机会变成 `False`，否则会死循环。

```python
count = 1
while count <= 3:
    print(count)
    count = count + 1
```

输出：

```text
1
2
3
```

## 3.4 for 循环

`for` 适合已知循环次数，或者需要遍历一组数据。

```python
for i in range(1, 4):
    print(i)
```

`range(1, 4)` 会产生 `1、2、3`，不包含 4。

`break` 会提前结束循环，`continue` 会跳过本次循环，直接进入下一次：

```python
for i in range(1, 6):
    if i == 3:
        continue
    if i == 5:
        break
    print(i)
```

## 小结

- `if / elif / else` 根据条件选择分支；
- `while` 适合次数不确定的循环，注意避免死循环；
- `for` 适合已知次数或遍历数据；
- `break` 结束整个循环，`continue` 跳过本次。
