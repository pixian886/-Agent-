## 学习目标

- 能把重复逻辑封装成函数
- 理解参数、返回值、默认参数和作用域
- 能使用标准库，并用 `try / except` 处理简单异常

## 4.1 为什么需要函数

当一段逻辑需要重复使用时，可以把它封装成函数。函数让代码更短、更清晰，也更容易修改。

```python
def greet(name):
    return f"你好，{name}"

print(greet("小明"))
print(greet("小红"))
```

## 4.2 定义与调用

函数用 `def` 定义，用函数名加括号调用。

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8
```

- `a`、`b` 是参数；
- `return` 把结果交给调用者；
- 没有 `return` 的函数默认返回 `None`。

<div class="v-callout is-tip">
  <strong>先定义，后调用</strong>
  <p>函数必须在调用之前定义。把函数写在文件前面，调用写在后面，是最简单的做法。</p>
</div>

## 4.3 参数与默认参数

函数可以有多个参数，也可以给参数设置默认值。

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

print(greet("小明"))
print(greet("小明", "早上好"))
```

调用时没有传 `greeting`，就会使用默认值 `"你好"`。

## 4.4 作用域、标准库与异常初识

函数内部定义的变量是局部变量，函数外部访问不到。需要跨函数共享的数据，可以通过参数传入、通过返回值传出。

```python
def calculate_total(price, count):
    total = price * count
    return total

print(calculate_total(12, 3))  # 36
```

Python 自带很多标准库：

```python
import math
import random

print(math.sqrt(16))        # 4.0
print(random.randint(1, 6)) # 1~6 之间的随机整数
```

程序可能因为输入不合法而报错。可以用 `try / except` 给出友好提示：

```python
try:
    age = int(input("请输入年龄："))
    print(f"你今年 {age} 岁")
except ValueError:
    print("请输入数字")
```

这样即使输入了文字，程序也不会直接崩溃。异常处理的完整用法会在 L09 展开。

## 4.5 函数作为参数

函数本身也是对象，可以像数字、字符串一样被传递。把函数传给另一个函数，可以让同一段逻辑适配不同操作：

```python
def double(x):
    return x * 2

def square(x):
    return x * x

def apply(func, value):
    return func(value)

print(apply(double, 3))  # 6
print(apply(square, 3))  # 9
```

`apply` 不关心传进来的是哪个函数，只负责调用它。后面做 Agent 工具注册时，就是用一个字典把工具名映射到函数，再按名字调用。

<div class="v-callout is-tip">
  <strong>函数名后面不加括号</strong>
  <p><code>apply(double, 3)</code> 传的是函数本身；<code>apply(double(3), ...)</code> 传的是调用结果。注意区别。</p>
</div>

## 小结

- 函数用 `def` 定义，用 `return` 返回结果；
- 参数让函数接收外部数据，默认参数可以省略部分输入；
- 局部变量只在函数内部有效；
- 标准库可以直接 `import` 使用；
- `try / except` 可以处理可预期的异常；
- 函数可以作为参数传递，这是工具注册的基础。
