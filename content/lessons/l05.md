## 学习目标

- 能用列表保存一组有序数据
- 能用字典保存键值对
- 能处理列表套字典这种常见结构

## 5.1 列表基础

列表用方括号表示，适合保存一组有顺序的数据。

```python
numbers = [3, 5, 2, 8]

print(numbers[0])   # 3
print(numbers[-1])  # 8
print(numbers[1:3]) # [5, 2]
print(len(numbers)) # 4
```

列表可以修改、追加和删除：

```python
numbers = [3, 5, 2, 8]
numbers.append(10)
numbers.remove(5)
numbers[0] = 30
print(numbers)  # [30, 2, 8, 10]
```

遍历列表：

```python
for number in numbers:
    print(number)
```

## 5.2 列表常用操作

```python
scores = [75, 88, 92, 60]

print(max(scores))                # 92
print(sum(scores))                # 315
print(sum(scores) / len(scores))  # 78.75
scores.sort()
print(scores)                     # [60, 75, 88, 92]
```

`in` 可以判断元素是否存在：

```python
print(88 in scores)  # True
print(100 in scores) # False
```

## 5.3 字典基础

字典用键值对保存数据，适合按名字查找。

```python
student = {
    "name": "小明",
    "score": 75,
}

print(student["name"])       # 小明
print(student.get("score"))  # 75
print(student.get("age", 0)) # 0
```

新增、修改和删除：

```python
student["age"] = 18
student["score"] = 80
del student["age"]
print(student)  # {'name': '小明', 'score': 80}
```

遍历字典：

```python
for key, value in student.items():
    print(key, value)
```

<div class="v-callout is-tip">
  <strong>什么时候用字典</strong>
  <p>当数据有明确字段名时，用字典比列表更清楚。例如一条留言用 <code>{"id": 1, "content": "Hello"}</code> 表示。</p>
</div>

## 5.4 嵌套结构与元组、集合

列表套字典，是 Web 应用里非常常见的数据结构：

```python
students = [
    {"name": "小明", "score": 75},
    {"name": "小红", "score": 92},
]

for student in students:
    print(student["name"], student["score"])
```

- 元组用圆括号表示，创建后不能修改；
- 集合用花括号表示，会自动去重；
- 只需要保存一组不重复的值时，可以用集合。

```python
point = (3, 5)
tags = {"python", "web", "python"}
print(tags)  # {'python', 'web'}
```

## 5.5 嵌套字典取值

真实接口返回的数据经常是“字典套字典”：

```python
students = {
    "小明": {"math": 92, "english": 85},
    "小红": {"math": 78, "english": 90},
}

print(students["小明"]["math"])  # 92
```

多层取值时，先取外层，再取内层。姓名可能不存在，用 `get` 兜底：

```python
name = "小刚"
student = students.get(name)

if student:
    print(student["math"])
else:
    print("未找到")
```

后面解析 JSON 时，就是在这个结构上再套一层列表或字典。

## 小结

- 列表有序、可修改，适合保存一组数据；
- 字典按键查找，适合保存有名字的字段；
- 列表套字典是接口与数据库数据的常见形式；
- 元组不可变，集合自动去重；
- 嵌套取值先外层再内层，缺失时用 `get` 兜底。
