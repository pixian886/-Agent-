## 学习目标

- 理解类与对象的关系
- 能定义 `__init__` 和实例方法
- 能创建对象并调用方法

## 6.1 类与对象

类可以理解成图纸，对象是按图纸造出来的房子。一个类可以创建很多对象。

```python
class Student:
    pass

student = Student()
print(student)  # 一个 Student 对象
```

## 6.2 属性与 `__init__`

`__init__` 是创建对象时自动执行的方法，用来保存初始属性。`self` 表示当前对象。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

student = Student("小明", 75)
print(student.name)   # 小明
print(student.score)  # 75
```

## 6.3 方法与封装

方法是定义在类里的函数，用来操作对象自己的属性。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_pass(self):
        return self.score >= 60

student = Student("小明", 75)
print(student.is_pass())  # True
```

调用方法时不需要手动传 `self`，Python 会自动把当前对象传进去。

## 6.4 为什么 Web 框架里有类

读 FastAPI 或其他框架的代码时，会看到类似这样的写法：

```python
class Message(BaseModel):
    content: str
```

这表示 `Message` 继承自 `BaseModel`。你只需要先把它当成固定写法，知道它用来描述数据结构即可，不需要现在就理解继承的全部原理。

在后面的留言板里，`Message` 类可以表示一条留言，`content` 是它的字段。

## 小结

- 类是模板，对象是实例；
- `__init__` 在创建对象时执行，用来初始化属性；
- `self` 指向当前对象；
- 方法可以读取和修改对象自己的属性；
- Web 框架中的模型类通常用来描述数据结构。
