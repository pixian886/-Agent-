## 7.1 JSON 是什么

JSON 是接口和配置文件最常用的数据格式。它只有两种结构：

- 对象：用花括号表示，对应 Python 的字典；
- 数组：用方括号表示，对应 Python 的列表。

值可以是字符串、数字、`true` / `false`、`null`，也可以是另一个对象或数组。

```json
{
  "name": "小明",
  "age": 18,
  "tags": ["python", "web"]
}
```

## 7.2 `json.loads` 与 `json.dumps`

`json.loads` 把字符串解析成 Python 数据；`json.dumps` 把 Python 数据写回字符串。

```python
import json

raw = '{"name": "小明", "age": 18}'
data = json.loads(raw)
print(data["name"])  # 小明

text = json.dumps(data, ensure_ascii=False)
print(text)  # {"name": "小明", "age": 18}
```

- `ensure_ascii=False` 让中文保持原样；
- `indent=2` 可以输出带缩进、方便阅读的 JSON。

<div class="v-callout is-tip">

## 7.3 文件读写

用 `with open()` 打开文件，代码块结束后会自动关闭文件。

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")

with open("notes.txt", "r", encoding="utf-8") as f:
    text = f.read()

print(text)
```

- `"w"` 表示覆盖写入，`"a"` 表示追加；
- 处理中文时明确写 `encoding="utf-8"`；
- 读文件前先确认路径存在。

```python
from pathlib import Path

path = Path("notes.txt")
print(path.exists())
```

## 7.4 编码、路径与常见错误

<div class="v-callout is-warn">
  <strong>FileNotFoundError</strong>
  <p>文件不存在或路径写错。先打印当前目录，或使用 <code>Path("notes.txt").exists()</code> 检查。</p>
</div>

<div class="v-callout is-warn">
  <strong>UnicodeDecodeError</strong>
  <p>文件不是 UTF-8 编码，或读取时没有指定编码。统一使用 <code>encoding="utf-8"</code>。</p>
</div>

`"w"` 会覆盖原文件内容；只想追加时用 `"a"`。

## 小结

- JSON 对象对应字典，JSON 数组对应列表；
- `json.loads` 解析字符串，`json.dumps` 生成字符串；
- `with open(..., encoding="utf-8")` 是读写文本的标准写法；
- 路径不存在、编码不一致是两个最常见的文件错误。
