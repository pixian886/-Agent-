## 学习目标

- 理解 URL、请求方法、请求头、请求体与状态码
- 能用 `requests.get` 带参数请求接口
- 能解析 JSON 响应，并处理超时与错误状态

## 8.1 URL、方法与状态码

一次 HTTP 请求至少包含四样东西：

- URL：请求地址，例如 `https://httpbin.org/get`；
- 方法：`GET` 获取数据，`POST` 提交数据；
- 请求头：身份、内容类型等信息；
- 请求体：POST 时携带的数据。

服务器用状态码表示结果：

| 状态码 | 含义 |
|-|-|
| `200` | 成功 |
| `401` | 未登录或 Key 无效 |
| `404` | 地址或资源不存在 |
| `500` | 服务器内部错误 |

## 8.2 `requests.get` 与 `params`

先安装 `requests`：

```bat
pip install requests
```

```python
import requests

response = requests.get(
    "https://httpbin.org/get",
    params={"city": "beijing"},
    timeout=10,
)

print(response.status_code)
print(response.url)
```

- `params` 会把字典拼到 URL 的查询字符串；
- `timeout` 防止请求一直卡住；
- `response.status_code` 是状态码。

## 8.3 `requests.post` 与 JSON

提交 JSON 数据时用 `json=`，`requests` 会自动设置 `Content-Type`：

```python
response = requests.post(
    "https://httpbin.org/post",
    json={"message": "hello"},
    headers={"Authorization": "Bearer demo-key"},
    timeout=10,
)

print(response.status_code)
```

需要传身份信息时，放在 `headers` 里，不要拼进 URL。

## 8.4 `response.json()` 与错误处理

只有状态码为 2xx 时，才把响应体当作正常结果：

```python
response = requests.get(url, params={"city": "beijing"}, timeout=10)

if response.status_code != 200:
    print("请求失败：", response.status_code)
else:
    data = response.json()
    print(data["city"], data["temperature"])
```

- `response.json()` 只能解析 JSON 响应，遇到 HTML 会抛异常；
- `response.raise_for_status()` 可以在 4xx / 5xx 时直接抛出 `HTTPError`；
- 超时、连接失败会在下一课详细处理。

## 8.5 真实 API 与 mock 接口

站内练习使用本地 mock 接口，不访问外网：

```text
http://127.0.0.1:8765/weather?city=beijing
```

返回：

```json
{"city": "北京", "temperature": 26}
```

在自己电脑上，可以把地址换成真实的公开 API，例如 `https://httpbin.org/get`。真实接口可能超时、限流或返回 4xx，这些都要在代码里处理。

<div class="v-callout is-tip">
  <strong>先看状态码，再解析 JSON</strong>
  <p>状态码不是 2xx 时，响应体可能不是 JSON。直接调用 <code>response.json()</code> 容易得到难以理解的报错。</p>
</div>

## 小结

- HTTP 请求由 URL、方法、请求头和请求体组成；
- `requests.get` 用 `params` 传查询参数，`requests.post` 用 `json=` 传 JSON；
- 先检查 `status_code`，再调用 `response.json()`；
- `timeout` 必须设置，避免请求一直卡住。
