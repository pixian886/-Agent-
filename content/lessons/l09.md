## 学习目标

- 能用 `try / except / else / finally` 捕获可预期的异常
- 能捕获 `requests` 的超时、连接错误与 HTTP 错误，并做有限重试
- 能用 `.env` 管理 API Key，不把 Key 写进代码或提交到 Git

## 9.1 `try / except / else / finally`

程序出错时，默认会中断并打印 traceback。可预期的错误应该被捕获并给出友好提示。

```python
try:
    a = int(input())
    b = int(input())
    result = a / b
except ValueError:
    print("请输入数字")
except ZeroDivisionError:
    print("除数不能为 0")
else:
    print(result)
finally:
    print("程序结束")
```

- `except` 按异常类型捕获，越具体越好；
- `else` 只在没有异常时执行；
- `finally` 无论是否出错都会执行。

## 9.2 捕获 `requests` 异常与重试

网络请求失败是常态，不是意外。常见异常：

- `requests.exceptions.Timeout`：超过 `timeout`；
- `requests.exceptions.ConnectionError`：连不上服务器；
- `requests.exceptions.HTTPError`：`raise_for_status()` 遇到 4xx / 5xx。

```python
import requests
from requests.exceptions import ConnectionError, HTTPError, Timeout

def fetch(url, times=3):
    for index in range(times):
        try:
            response = requests.get(url, timeout=5)
            response.raise_for_status()
            return response.json()
        except (Timeout, ConnectionError) as exc:
            print(f"第 {index + 1} 次失败：{exc}")
        except HTTPError as exc:
            print(f"服务返回错误：{exc}")
            break
    return None
```

<div class="v-callout is-warn">
  <strong>重试要有上限</strong>
  <p>只对超时、连接失败和 5xx 重试；401、404 这类错误重试也不会变好。重试次数必须有限。</p>
</div>

## 9.3 `os.getenv` 与 `.env`

API Key 不应该写进代码。把 Key 放在 `.env` 文件里，用 `python-dotenv` 读取：

```bat
pip install python-dotenv
```

`.env` 文件内容：

```text
API_KEY=demo-key-123
```

```python
import os

from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv("API_KEY")

if not api_key:
    raise RuntimeError("没有读取到 API_KEY，请检查 .env")
```

- `.env` 只放在本机，不提交到 Git；
- 仓库里只提交 `.env.example`，写占位值；
- 换 Key 时只改 `.env`，代码不用动。

```text
.env
.env.example
```

## 9.4 Key 安全、日志与轨迹

<div class="v-callout is-warn">
  <strong>Key 不能出现在这些地方</strong>
  <p>代码字面量、日志、截图、Git 提交。日志里只记录请求地址和状态码，不打印 <code>Authorization</code> 头的值。</p>
</div>

用 `logging` 记录每一步，方便排查，也是后面 Agent 轨迹的雏形：

```python
import logging

logging.basicConfig(level=logging.INFO)

logging.info("请求 %s", url)
logging.info("状态码 %s", response.status_code)
logging.info("响应字段 %s", list(data.keys()))
```

## 9.5 小练习

- 捕获除零异常，输出友好提示；
- 对失败函数做最多 3 次重试，全部失败返回「重试失败」；
- 在本机用 `.env` 保存 Key，并把它放进请求头。

## 小结

- 捕获具体异常，不用裸 `except`；
- 网络请求要设 `timeout`，重试要有限；
- Key 放 `.env`，用 `os.getenv` 读取；
- 日志记录步骤，但不记录 Key。
