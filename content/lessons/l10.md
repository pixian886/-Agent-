## 10.1 数据库与表

数据库把数据保存在表里。表有列（字段）和行（记录），每行通常有一个主键来唯一标识自己。

SQLite 是一个单文件数据库，不需要安装数据库服务，适合本地练习。

## 10.2 SQL 增删改查

```sql
CREATE TABLE messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO messages (content) VALUES ('Hello, SQLite');

SELECT id, content, created_at FROM messages ORDER BY id DESC;

UPDATE messages SET content = '更新后的内容' WHERE id = 1;

DELETE FROM messages WHERE id = 1;
```

`WHERE` 用来筛选记录，`ORDER BY` 用来排序。

## 10.3 Python 操作 SQLite

```python
import sqlite3

conn = sqlite3.connect("messages.db")
cursor = conn.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
)
""")

cursor.execute("INSERT INTO messages (content) VALUES (?)", ("Hello",))
conn.commit()

cursor.execute("SELECT id, content FROM messages ORDER BY id DESC")
print(cursor.fetchall())

conn.close()
```

## 10.4 参数化查询与留言表

不要把用户输入直接拼进 SQL 字符串，否则可能出现 SQL 注入。使用 `?` 占位符，把数据作为第二个参数传入：

```python
content = "用户输入的内容"
cursor.execute("INSERT INTO messages (content) VALUES (?)", (content,))
```

<div class="v-callout is-warn">
  <strong>不要这样写</strong>
  <p>cursor.execute(f"INSERT INTO messages (content) VALUES ('{content}')") 会把用户输入当成 SQL 的一部分，存在注入风险。</p>
</div>

## 小结

- 表由列和行组成，主键唯一标识一行；
- SQL 的四个基本操作是增、删、改、查；
- Python 用 `sqlite3` 连接数据库并执行 SQL；
- 始终使用 `?` 参数化查询，避免 SQL 注入。
