## 11.1 Web 请求与响应

浏览器访问一个地址时，会向服务器发送 HTTP 请求；服务器处理后再返回响应。常见请求方法：

- `GET`：获取页面或数据；
- `POST`：提交表单或新增数据。

常见状态码：

- `200`：成功；
- `404`：页面不存在；
- `500`：服务器内部错误。

## 11.2 FastAPI 最小应用

安装依赖：

```bat
pip install fastapi uvicorn
```

创建 `main.py`：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def index():
    return {"message": "Hello, FastAPI!"}
```

启动：

```bat
uvicorn main:app --reload
```

浏览器打开 `http://127.0.0.1:8000`，就能看到返回的 JSON。

## 11.3 Jinja2 模板

返回 HTML 页面需要模板。FastAPI 使用 Jinja2：

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()
templates = Jinja2Templates(directory="templates")

@app.get("/")
def index(request: Request):
    messages = ["第一条留言", "第二条留言"]
    return templates.TemplateResponse(
        "index.html",
        {"request": request, "messages": messages},
    )
```

`templates/index.html` 里可以用循环渲染留言：

```html
<ul>
  {% for message in messages %}
    <li>{{ message }}</li>
  {% endfor %}
</ul>
```

## 11.4 表单提交与写入数据库

接收表单需要 `Form`，提交后可以调用上一课的数据库函数，把留言写入 SQLite：

```python
from fastapi import FastAPI, Form
from fastapi.responses import RedirectResponse

@app.post("/messages")
def create_message(content: str = Form(...)):
    save_message(content)
    return RedirectResponse("/", status_code=303)
```

使用 `Form` 需要安装 `python-multipart`：

```bat
pip install python-multipart
```

## 小结

- 浏览器通过 HTTP 请求访问服务器；
- FastAPI 用路由函数处理请求；
- Jinja2 负责把数据渲染成 HTML；
- 表单提交后写入数据库，再重定向回列表页。
