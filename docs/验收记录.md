## 5. 已知边界

- 服务只监听 `127.0.0.1`，仅本机访问；
- 判题在本机执行学生代码，不是安全沙箱，不部署公网；
- 未实现 CSRF Token、登录限流与验证码；
- 代码编辑器为原生 textarea，无语法高亮；
- 所有测试用例对学习者可见，便于自测；
- 「重做」为当前页面临时解锁，未提交时刷新会回到通过锁定状态；
- 仅支持 Python 标准库判题，不支持第三方包。

**验收通过。**
